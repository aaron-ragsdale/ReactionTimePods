# Reaction Pods — Version 1

This folder contains the Version 1 design. The current setup uses one ESP32 to control four wired, individually illuminated physical push-button targets.

- [Firmware](firmware/): Arduino ESP32 sketch and dependencies
- [Interface](interface/): source for the web dashboard served by the ESP32
- [STL files](stl/): printable 3D models
- [Build guide](BUILD_GUIDE.md): assembly tutorial (draft)

**Status:** Initial working prototype. Files and detailed instructions will be added here. Keep Version 1 hardware and firmware together as later versions evolve.
