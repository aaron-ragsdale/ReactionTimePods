# Version 1 — ESP32 firmware

Place the working Arduino sketch (`.ino`) and any additional source files here.

The ESP32 controls four physical buttons and their addressable LEDs, hosts a Wi-Fi access point, serves the dashboard, and records gameplay metrics.
